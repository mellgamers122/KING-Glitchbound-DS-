# KING: GLITCHBOUND

Homebrew de plataforma e aventura para Nintendo DS.

Gui "KING" e puxado para o NEXUS, um universo corrompido formado por fragmentos de diferentes generos de videogame. Para voltar para casa, ele precisa recuperar os Fragmentos de Save.

## Build atual
- D-Pad: movimento
- A: pulo
- B: dash
- Duas telas
- Primeiro Fragmento de Save

O GitHub Actions compila automaticamente o projeto e gera `KING_Glitchbound.nds` como artifact.
